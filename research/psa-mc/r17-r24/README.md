# PSA MC-R17–R24 — consolidated research candidate

Research-only, based on MC-R9–R16 archive SHA-256 `88630083b384f79ef891d05cb1541d4eaa24299863a9c24f5c01adc5ecc13252`. Its file manifest was verified. No production changes. All fixtures here are synthetic. The local private-photo experiment is reported only as aggregate counts; no private pixels, answer keys, or coordinates are included.

## Findings and status

- R17: shared outline and glyph extraction between Python discovery paths. Existing modules remain modular. Fresh challenges exposed faulty multi-digit grouping; changed adjacency to use bounding-box gaps and overlap, rather than a fixed center spacing relative to the first glyph's height.
- R18: 12 new synthetic forms, 168 genuine rows, 4 fonts, 4/5-choice blocks, group gaps, partial/absent rows, missing headers/numbers, numbering restarts, shadow and low resolution. Raw combined template path before correction mapped 162 rows with 128 exact recognized numbers and 10 wrong labels. After correction: 168 rows, 148 exact numbers, zero wrong labels; 4 false proposals, 2 initially confirmed on an unnumbered sheet. SVM substitution for candidate digits mapped 167 rows, 145 correct numbers, zero wrong labels; conservative hybrid matched template mode. Retain templates as default. This is not a full alternate-character contextual decoder or an independent test. `fresh.log` records pre-correction raw outputs; `fresh-results.json` records post-correction raw outputs.
- R19: two newly seeded mixed synthetic pages using the prior actual NR Python reference. 44 genuine MC rows recovered, 9 false MC rows, all 9 marked conflicts after reconciliation. One received an NR-preferred recommendation; no rows deleted. Strong malformed NR evidence can challenge MC but does not authorize NR mapping. The new completeness safeguard marks rows in a family without any recognized question number as requiring review; 44 true unnumbered MC rows are also review-only. This is conservative, not proof of an erroneous row. The score helper counts absent labels as equal for null ground truth; ignore label counts in `arbitration-results.json`. No automatic saving or production arbitration authorized.
- R20: the new suite compared the first-cycle engine, consolidated template/SVM/hybrid, and ablations removing number or header paths. First cycle 154/168, corrected template 168/168, no-number 159/168, no-header-only-recovery 167/168 (header evidence inside number-led hypotheses remains). Independent tester not available; these are fresh but self-authored development fixtures used for correction. The pinned deployed detector was not rerun on these newly drawn rasters; earlier pinned baseline remains separate. This stage's independent three-way comparison is outstanding.
- R21: this archive freezes a **candidate**, not an independently accepted reference. Coordinates are rectified raster pixels. Each row contains `points`, `observed`, `decision`, optional `number` (OCR suggestion only), `review_reasons`, `geometry_observed`, `number_provenance`, optional `arbitration`. `confirmed` does not guarantee question count, exact numbering, or permission to save. Teacher review of full template remains required. Affine refinement is not included in the JS port; default reference path leaves it off.
- R22/R23: native JS structural inference port plus approximate native raster/glyph front end, reusing prior NR HOG and pixel code. Shared input feature equivalence across 24 sheets: 344/344 proposals match centers, decisions, numbers and observed masks exactly. Full raster runs: both map 336/336 genuine rows, both confirm 262 true rows and have zero false confirmations under the finalized review rule. Python has 8 extra provisional proposals, native 12. Native raster is NOT fully equivalent. Fresh 12 native pages have 148 correct recognized numbers and zero wrong labels among matched true rows. Native timings 0.287–0.683s in local Node only (excludes bank generation, NR search, page rectification). Synthetic tests are development evidence, not accuracy estimates for field use. JS consumes externally obtained NR proposals; full joint native execution and cross-type equivalence remain outstanding. Existing SVM helper is included for reuse but not invoked by the MC native default. Bank is 699,840 bytes of computed float32 features, no font files. Both Python and native on the known private blank photo, resized 850×1100, produce 14 proposals, labels 1–14, 2 headers, 0 reviews. Aggregate only, not measured localization or an independent photo.
- R24: worker client and Node worker harness pass normal discovery, malformed raster, corrupt feature bytes, corrupt label metadata, cancel and timeout. Chromium navigation blocked by administrator even on a data URL. Browser/offline/PWA/mobile tests, automatic page rectification, product integration, memory profiling, and independent acceptance remain outstanding. No deployment readiness claim. Native raster limits and worker termination are preliminary protections; further resource/abuse testing needed.

## Reproduce

Python 3.13, Node 22, numpy, scipy, opencv-python, Pillow, joblib, scikit-learn. `glyphs.py` refers to generic local system font paths. Fonts not bundled; differences in installed fonts and OpenCV affect reproduction. The included feature bank was generated locally from available fonts. The worker pins its bytes and label order; regenerating a different bank requires explicit hash revision. For SVM and NR cross-check, extract trusted previous PSA NR R13–R16 archive into a separate local folder. Do not load untrusted pickle files. No internet or inference service required.

From the archive root:
```
OPENBLAS_NUM_THREADS=1 python fresh_eval.py /path/to/portable/regenerated-svm.pkl
OPENBLAS_NUM_THREADS=1 python arbitration_check.py /path/to/portable /path/to/portable/regenerated-svm.pkl
OPENBLAS_NUM_THREADS=1 python make_native_fixtures.py
cd native
node equivalence.mjs /tmp/mc_native_fixtures
node raster_check.mjs /tmp/mc_native_fixtures
node worker-check.mjs /tmp/mc_native_fixtures
```
`make_native_fixtures.py` regenerates synthetic grayscale fixtures and feature/ground-truth JSON under `/tmp/mc_native_fixtures`. It also regenerates the bank in `native/`. Exact equivalence is defined for the same extracted features, not pixel processing. Ground-truth row match requires same choice count, all centers within 4 raster pixels and one-to-one row assignment. Review status measures decision on a proposal, not teacher confirmation. Fixture generator and evaluation are not independent.
