# PSA MC structured discovery — initial MC-R1–R8 research cycle

Research branch based on deployed app source `4d3248c28190ef6984360831e3aecdff44d36a9b`. Development fixtures and PSA self-evaluation, not independent validation or production integration. No private form pixels, labels, coordinates or model training from private data included. No changes to app. Python OpenCV/SciPy prototype; baseline is original JavaScript. Use Python 3, numpy, scipy, opencv-python, pillow, joblib and scikit-learn. Font paths in glyphs.py; absent files skipped. Exact reproducibility requires matching fonts and environment.

Run `node research/psa-mc/baseline.mjs` in pinned app checkout; original baseline actually executed with fetched JS modules adapted to a V8 module loader. Reproducer uses native imports. Run `python check.py`, `python structured_check.py`, `python stress_check.py` in this directory. Optional `python glyphs.py /path/to/r5-models.pkl` (trusted synthetic NR archive from previous research only; never load untrusted pickle). Existing SVM is not needed by the MC prototype. All private-image diagnostics were run locally and are reported only in aggregate.

## MC-R1 actual baseline
Six synthetic rasters, identical FNV hashes in JavaScript and Python. Ground truth all 14 rows, 4 choices except five-choice case. Criterion all centers within 2 page points (3 raster pixels); label numbering not measured for these unlabelled forms. Baseline exact rows: clean 14, filled circular gap distractors 14, partial (one removed and one broken outline) 13 (interrupted-grid), missing full row 13 (no warning), five-choice 14, mixed NR 14 (2 NR groups). No extra MC rows. A seventh distinct unlabelled control with real empty circles in both gaps produced 16 MC items and no issues. Does not establish the exact cause of ISTE phantom rows on its unavailable synthetic fixture.

## MC-R2/R5 outline and reconstruction
Contour candidates from Otsu/adaptive thresholds; polar annular ink, angular coverage, low interior/exterior ink; fit horizontal 4/5-choice runs and shared columns. Preserve observed centers. Infer missing choices only if at least n-1 actual circles in a row; mark review. Do not infer whole rows from pitch alone. On the six identical baseline rasters, 83/84 correct row mappings (vs 82/84 baseline), no extra rows; two provisional on partial. Complete absent unlabelled row remains missing. Four/five choice assumptions, limited tolerance to skew and overlapping columns; internal 'confirmed' is a prototype decision, not accepted product data.

## MC-R3/R4 glyph pilot
Use the frozen NR HOG/SVM on standalone synthetic digits after canonical preprocessing. Independent HOG nearest-template bank covers digits and A–E using generic fonts. Initial noisy-image normalization was defective (24/120 SVM, 20/120 template digit, 8/60 letter); corrected by suppressing sub-0.10 noise before normalizing. On the same development test, 120/120 digits for both classifiers, 60/60 letters for bank, three held-out-from-bank font families. One intended font absent. SVM training may overlap those font families; not an independent holdout from the NR SVM. Samples are presegmented single characters; not OCR field accuracy. Existing SVM usable but no evidence yet it is necessary; template bank used for fusion. Component analysis finds A–D/E sequences without outline input; number tokens use nearby components and require >=3 consecutive integer labels. Header-assisted number search is not yet a fully independent number-only proposal path.

## MC-R6/R7/R8 structured evidence
Six additional labelled synthetic pages (different from baseline): clean, missing entire bubble row, partial outline, empty ring distractor, five choices, shadow. Fused 84/84 correct row geometries within 4 pixels, one provisional entirely missing row, one provisional partial, two false but explicitly review-only unlabelled rows in gaps; 82 confirmed correct, 2 provisional correct; no false confirmed on this labelled suite. Empty ring distractor outline-only confirmed 16 including two false; fusion retains both as conflict reviews, not automatic deletion. All 14 numbers labelled except shadow (12), no verified field-wide OCR false-positive rate. Ground truth coordinates from drawing code. No comparisons with actual app on these six labelled rasters. Mixed NR simple fixture and known private photo had no MC false positives; more real NR variants required. Header and sequence evidence optional; missing/unreliable labels must not veto real bubbles without review.

Known private Physics photograph resized to 850x1100: outline-only and fused 14/14 correct rows against approximate visual annotations (3px per-center tolerance), no extra; both headers and all question numbers recognized. Half-size: 14/14, only 4 labelled; shadow: 14/14, all 14 labelled; unrectified 3-degree rotation: 12/14, 13 proposals, one incorrect; global ring-angle deskew restored 14/14 (one review), all 14 labels. Same image variants, not separate physical captures. Private annotation not independent or exact. Eight synthetic rotated pages: before 50/112 correct (sum of 0,12,0,12,0,14,0,12), after 112/112; 4 extra circle rows in conflict review after correction, none automatically confirmed. Mild synthetic projective warp 14/14; stronger warp 5/14 (one review); geometric registration needed. Rotation correction requires repeated consistent nearby ring pairs and is not a substitute for page rectification. No mobile speed/memory or native JS port yet. No exact ISTE fixture or direct baseline on private photo; no claim of general accuracy. No independent holdout.

## Next priorities
Obtain exact ISTE synthetic fixtures and compare both engines under identical rectification, add labelled cases with diverse fonts, missing headers/labels, misleading sequence, long gaps, strong perspective, MC/NR interactions and edge cases. Improve row-level provenance and conflict treatment. Explore independent number-first path and alternative lattice hypotheses (shifted columns and local affine axes) beyond initial observed-row fit. Require independent verification before integration. No speculative optimization.
