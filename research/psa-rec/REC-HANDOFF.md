Files: compact-reference.js, completion-with-patches.js (research-only adapted copy), rec-r1-test.mjs and results. Store exact 41x41 rounded grayscale patch per mapped bubble, in profile order, plus one-byte availability flag. Preserve the existing group's orientation, sampling, local pose and background strip. Bind envelope to id, revision, page and components. Require teacher-confirmed blank and registered pose. Limit to 1200 bubbles. Unobservable patch or suspect MC baseline ink (raw > .105) is unavailable; no claim that NR or MC blankness is established. Whole-reference registration/compatibility must remain independent. For a 72-bubble profile: 121104 bytes of typed-array payload, excluding metadata (vs 742600–2833600 decoded RGBA bytes); at maximum 1200 bubbles: 2018400 bytes. Compressed JPEG storage comparison not measured; patch storage can be larger than JPEG. No measured speed/peak memory result yet. If storing patches, preserve typed arrays rather than base64 in IndexedDB; validate schema, binding, sampler version, length, availability, integrity and bounds; safe fallback on missing/malformed data; re-enroll on profile edits. Integrate with existing registered blank during authoring only after teacher confirmation; support existing saved JPEGs/legacy profiles. Need backup/privacy policy, enrollment verification and corrupted/marked reference checks. Do not silently fall back to a different authoritative recognizer.
Actual frozen model: four reference scales by three scan scales = 12 comparisons, nine items per comparison, 108/108 exact serialized outputs; 20/20 assertions. All 72 patches in each clean reference available. Six invalid inputs rejected; eight suspect MC bubbles in synthetic marked reference flagged, unknown IDs and caller mutation isolation passed. Known pose and synthetic raster only; no real JPEG or app/worker timing. Candidate adapter accepts reference.patchFor(groupId,symbol) in addition to existing whole-image reference. Missing patches cause no-reference evidence and withhold CPAS MC gate rather than invent a patch. Research copy not intended as second production engine; adapt existing completion module directly.

No new confidence calibration, no actual handwriting inference comparison, no policy adoption.
