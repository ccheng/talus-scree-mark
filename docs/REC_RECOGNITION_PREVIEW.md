## Template authoring

- Confirm the page and its response regions as usual. Leave **Save recognition samples from this unmarked template** selected to enroll the blank during **Confirm and save template**.
- Compact enrollment keeps rounded grayscale bubble patches and availability flags, up to 2,018,400 bytes for 1,200 bubbles. The record is checked against the exact revision and geometry and validated for corruption before use. Scan-time reference decoding and registration are eliminated for this path. A legacy saved blank can still be used.
- For a confirmed NR block, select **Find handwriting boxes**. Review the numbered outlines on the blank, select the correct groups and save. The preview only uses teacher-confirmed geometry for that revision. Changes to the draft pose or mapping invalidate the proposals. An optional explicit JSON map is available for legacy profiles. Failure to locate boxes leaves the optical comparison available.
- Evidence is stored on the device beside the profile. The main profile and backup schemas remain compatible. The sidecar is outside backups. Re-enroll it when moving devices or creating a new revision. Availability and model failures do not alter Established.

## Interpretation

- **Spatial** uses the existing frozen CPAS completion model and gate.
- **Optical agreement** requires an observable matching reference and a definitive Established read that matches the spatial optical literal. The diagnostic export also includes strict agreement, which requires the spatial confidence gate.
- **Logistic stacking** uses the unmodified REC-R7 coefficients and threshold `0.7862137339932567`. It requires a single admissible candidate and withholds conflicting or competing observations. Its score expresses fit to the experimental marking policy.
- NR optical and handwriting observations remain advisory. Each NR position exports outline coverage, selected pose and maximum page-to-block displacement relative to its radii. This displacement relates two estimates. Only independent physical truth measures alignment error.
- The comparison highlights differences and inspection reasons. **Show all responses** exposes each candidate on each item. Handwriting never substitutes a bubble selection.

Frozen sources are REC-R1–R6 `6c2fba7cddf58841dddb1f645413827f0c4b1d9e` and REC-R7 `9ca141ee4a3a4a4ddb862249308a3f239bd55ae9`. No model fitting or threshold selection was performed.
