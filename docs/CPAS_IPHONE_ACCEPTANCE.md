# CPAS preview on iPhone

Open the [CPAS development preview](https://ccheng.github.io/talus-scree-mark/cpas-preview/?cpas=preview) in Safari. Use your own classroom form, one unmarked original, and a small stack of de-identified completed sheets or teacher copies with authentic classroom marking. Use an ordinary sheet from another test for the wrong-layout check.

1. Select an existing template or create it from the blank. Confirm a batch using your normal workflow. Expand **Blank reference and handwriting setup** and choose a photo of the same unmarked original. The preview saves it for that revision.
2. Scan three to five sheets using the camera. Include a clean sheet and any naturally faint, partially filled, erased or competing marks. Compare the Established result with the CPAS cards. Note whether each card identifies the right question and helps you decide what to inspect. **Show all responses** reveals agreement and experimental reads.
3. Scan the different layout against the selected template and record whether it prompts a retake. Return to the correct form. Check that normal grading and manual corrections still use Established.
4. When the app says **Offline ready**, enable airplane mode, fully close and reopen the preview, and scan another sheet. The blank should be available when the same revision is selected. To try Home Screen mode, add the preview from Safari while online and repeat this check.
5. Record the iPhone model, iOS version, build shown in the app, approximate time from capture to Established and then to comparison, and any freezes, reloads, loss of saved reference or confusing cards. Note only the question numbers and observed states when sharing feedback. A diagnostics export contains response evidence and can stay on the device.

Handwriting is optional. It is evaluated only when there is a matching box map for that template revision. The normal iPhone evaluation can proceed with optical observations.
